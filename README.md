# CampusSync 🎓

**CampusSync** is an all-in-one AI-powered productivity platform designed to solve core student challenges—from optimizing resumes for job applications to summarizing study notes and finding project partners.

---

## 🎯 Problem Statement & Solution

* **The Problem:** Students often struggle to pass automated HR filters (ATS), spend hours digesting lengthy academic documents, and find it difficult to find reliable teammates for technical projects.
* **The Solution:** CampusSync unifies dynamic resume parsing, document summarization, and skill-based collaborator matching into a single fast, modern web application.

---

## 🚀 Key Features

* **📄 Dynamic ATS Resume Analyzer:** Real-time PDF text extraction that dynamically calculates an ATS compatibility score, identifies missing domain keywords, checks standard resume sections, and provides instant step-by-step suggestions.
* **📝 AI Document Summarizer:** Extracts core concepts, key takeaways, and flashcard-style summaries from notes and study materials.
* **🤝 Teammate Matcher:** Algorithms designed to help students connect with peers based on complementary technical skills and project needs.
* **⚡ Instant Live Feedback:** Responsive, clean UI providing immediate visual metrics without static or hardcoded outputs.

---

## 🛠️ Architecture & Tech Stack

* **Frontend:** React, TypeScript, Vite, Tailwind CSS
* **Parsing Engine:** Client/Server PDF Text Parsing & Custom Matching Logic
* **Deployment & Hosting:** Vercel (CI/CD connected to GitHub repository)

---

## 💡 Key Learnings & Future Roadmap
