# CampusSync 🚀

CampusSync is an all-in-one web platform designed to streamline student productivity, team collaboration, and career preparation through integrated artificial intelligence tools.

---

## ✨ Key Features
* **AI Document Summarizer:** Instantly condenses dense study notes and PDFs into core concepts.
* **Resume ATS Checker:** Analyzes resumes against industry standards to provide actionable improvement tips and ATS scores.
* **Teammate & Study Finder:** Connects students for project collaboration and group learning.

---

## 🛠️ Tech Stack
* **Frontend:** React, Tailwind CSS, JavaScript 
* **Backend:** Node.js, Express js
* **AI Integration:** Google Gemini APIs
